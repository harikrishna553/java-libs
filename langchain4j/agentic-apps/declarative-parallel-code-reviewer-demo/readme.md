Build the application using Maven:

```bash
mvn clean package
```
Run the generated executable JAR:

```java
java -jar ./target/declarative-parallel-code-reviewer-demo-1.0.0.jar
```

```bash
$ java -jar ./target/declarative-parallel-code-reviewer-demo-1.0.0.jar 
Enter the code file path to review the code
```
Enter any code file path for the Agent to start review
